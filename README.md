# ACXA Network landing page

A responsive, dependency-free landing page for ACXA's dedicated distributed ledger vision. The messaging describes planned node infrastructure and Mobile Money API connectivity, not a launched network or live fiat corridors.

## Run locally

```sh
python3 -m http.server 8080
```

Open `http://localhost:8080` in a browser. The site uses Google Fonts when available and local system-font fallbacks otherwise.

## Files

- `index.html`: content, navigation, and metadata
- `styles.css`: responsive visual design and animations
- `script.js`: accessible mobile navigation and copyright year
- `assets/`: optimized versions of the ACXA logos supplied for this page
